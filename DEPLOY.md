# Deploying Green Decor Interior Design to GitHub Pages

## Why you saw a blank screen

GitHub Pages was serving the **repository root** instead of the **built `dist/` folder**.

The `index.html` in the project root is a Vite *source* file. Its last line is:

```html
<script type="module" src="/src/main.tsx"></script>
```

Browsers cannot run TypeScript/JSX. That request fails with a 404, nothing is rendered
into `<div id="root"></div>`, and the result is a white page.

The real website is generated by `npm run build` into **`dist/index.html`**. Thanks to
`vite-plugin-singlefile`, that file is fully self-contained — all JavaScript and CSS are
inlined, so it works at any URL, including `https://<user>.github.io/<repo>/`.

---

## Option 1 — Automatic deployment (recommended)

A workflow is already included at `.github/workflows/deploy.yml`. It builds the project
and publishes `dist/` on every push.

**One-time setup:**

1. Push this project to GitHub (branch `main` or `master`).
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
   (Do *not* pick "Deploy from a branch" — that is what caused the blank page.)
4. Push any commit, or go to the **Actions** tab and run **Deploy to GitHub Pages** manually.

Your site appears at `https://<username>.github.io/<repository>/` in ~1 minute.
Every future `git push` redeploys automatically.

---

## Option 2 — Manual deployment from a branch

If you prefer not to use Actions:

```bash
npm install
npm run build
```

Then publish the contents of `dist/`:

- **Easiest:** copy `dist/index.html` into a `docs/` folder at the repo root, commit it,
  and set **Settings → Pages → Source** to *Deploy from a branch* → `main` / `docs`.
- Or commit the folder directly (it is gitignored, so force-add it):
  ```bash
  git add -f dist
  git commit -m "Deploy site"
  ```

Because the build is a single self-contained file, you can also just upload
`dist/index.html` to any static host (Netlify, Vercel, cPanel, Hostinger) as `index.html`.

---

## Verifying it worked

Open the deployed URL and press **F12 → Console**.

| What you see | Meaning |
| --- | --- |
| No errors, site loads | Working correctly |
| `404` for `/src/main.tsx` | Still serving the repo root — use Option 1 |
| `Failed to load module script ... MIME type "text/html"` | Same cause as above |
| Blank page, no network errors | Hard-refresh with `Ctrl+Shift+R` to clear the cached old page |

> **Tip:** GitHub Pages caches aggressively. After your first successful deploy, always
> hard-refresh (`Ctrl+Shift+R`, or `Cmd+Shift+R` on Mac) before judging the result.
